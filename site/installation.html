Installer NedoTab

Cinq minutes, sur Windows comme sur macOS. Vous avez seulement besoin de Google Chrome.

  1. Téléchargez le fichier

    Télécharger NedoTab %VERSION% (fichier .zip de %ZIP_TAILLE%).

    Empreinte SHA-256 : %ZIP_SHA256%

  2. Décompressez-le dans un dossier que vous garderez

    Sur Windows : clic droit sur le fichier, puis Extraire tout. Sur macOS : double-clic sur le fichier.

    Placez le dossier obtenu à un endroit où il restera, par exemple Documents/NedoTab. Chrome lit l'extension dans ce dossier à chaque démarrage : s'il est supprimé ou déplacé, l'extension cesse de fonctionner.

  3. Ouvrez la page des extensions de Chrome

    Copiez cette adresse, collez-la dans la barre d'adresse de Chrome et appuyez sur Entrée. (Une page web ne peut pas ouvrir cette adresse directement.)

    chrome://extensions

  4. Activez le mode développeur

    L'interrupteur se trouve en haut à droite de la page.

  5. Chargez l'extension

    Cliquez sur Charger l'extension non empaquetée, puis choisissez le dossier décompressé à l'étape 2 : celui qui contient le fichier manifest.json. NedoTab apparaît dans la liste.

  6. Ouvrez un nouvel onglet

    Appuyez sur Ctrl + T (⌘ + T sur Mac). Chrome demande s'il faut revenir à la page de Google : choisissez Conserver.

  7. Ajoutez vos sites

    Cliquez sur + pour ajouter un site. Pour chercher, cliquez dans la page puis tapez / : à l'ouverture d'un onglet, Chrome place d'abord le curseur dans sa barre d'adresse.

Pourquoi le mode développeur ?

NedoTab n'est pas publié sur le Chrome Web Store. Le mode développeur est la façon prévue par Chrome pour installer une extension depuis un dossier de votre ordinateur.

Chrome peut afficher de temps en temps un avertissement au sujet des extensions en mode développeur. Il ne signale pas un problème avec NedoTab : vous pouvez le fermer.

Un souci ?

« Le fichier manifeste est introuvable »

Le dossier choisi n'est pas le bon. Choisissez le dossier qui contient directement manifest.json, pas un dossier au-dessus.

Mon nouvel onglet n'a pas changé

Vous avez probablement répondu « Revenir » à la question de Chrome. Ouvrez chrome://extensions, désactivez puis réactivez NedoTab, ouvrez un nouvel onglet et choisissez Conserver.

Je ne vois pas « Mode développeur »

Votre Chrome est sans doute géré par une entreprise ou une école, qui a désactivé cette option. Seul l'administrateur peut l'autoriser.

Pour installer une nouvelle version plus tard, suivez le guide de mise à jour.
