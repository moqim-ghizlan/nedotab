Questions fréquentes

Est-ce gratuit ?

Oui. NedoTab est gratuit et ne contient pas de publicité.

Mes données sont-elles envoyées quelque part ?

Sans compte, non : vos sites, dossiers et réglages restent dans le navigateur, sur votre ordinateur. Si vous vous connectez avec Google, ils sont enregistrés sur votre compte (Google Firebase) pour les retrouver sur vos autres appareils. Le détail est sur la page Confidentialité.

Fonctionne-t-il sur Edge, Brave ou Opera ?

Oui, ces navigateurs acceptent les extensions de Chrome. La connexion Google y passe par une fenêtre Google classique (testée dans Brave). NedoTab est d'abord conçu et vérifié pour Google Chrome.

Comment le désinstaller ?

Ouvrez chrome://extensions et cliquez sur Supprimer sur la carte NedoTab. Attention : vos sites enregistrés sont effacés avec l'extension. Vous pouvez ensuite supprimer le dossier décompressé.

Pourquoi / ne marche-t-il pas tout de suite ?

À l'ouverture d'un nouvel onglet, Chrome place le curseur dans sa barre d'adresse : la touche va donc dans la barre d'adresse. Cliquez dans la page (ou appuyez sur Tab), puis tapez /.

Puis-je exporter mes sites ?

Oui : Réglages → Mes données → « Exporter mes données » télécharge un fichier nedotab-AAAA-MM-JJ.json (avec vos sauvegardes si vous êtes connecté). « Importer un fichier » le reprend : remplacer votre grille (une copie de sécurité est gardée) ou fusionner (les sites absents sont ajoutés dans un dossier).

Comment supprimer mon compte et mes données ?

Réglages → Compte → « Supprimer mon compte ». Votre compte, vos sites, réglages, sauvegardes et fonds d'écran enregistrés en ligne sont supprimés définitivement. Exportez vos données avant si vous voulez les garder.

Comment mettre à jour sans perdre mes sites ?

En remplaçant le contenu du dossier, sans supprimer l'extension. Voir le guide de mise à jour.

Sur iPhone ou iPad, mes sites peuvent-ils disparaître ?

Dans un onglet Safari, oui : Safari peut effacer les données d'un site que vous n'avez pas ouvert depuis plusieurs jours (protection contre le pistage). Pour les garder, connectez-vous avec Google : vos sites sont alors enregistrés sur votre compte et reviennent dès la connexion. Vous pouvez aussi exporter vos sites dans un fichier (Réglages → Données).
